Data: NASA FIRMS, live API, MODIS NRT (since 2000) + VIIRS NOAA-20 NRT (not the retired Suomi NPP feed — Suomi NPP stopped delivering data Nov 2, 2026) active-fire detections, September 2026, over a bounding box covering all of Kazakhstan. The gap: VIIRS's finer ~375m resolution reliably detects more, smaller fires than MODIS's ~1km resolution — on the real peak day (Sep 7) that's 656 MODIS detections vs. 2,647 VIIRS, the same country, the same week. Baseline: this month's own median daily total (753), used as an honest proxy — a true multi-year seasonal climatology needs a multi-year FIRMS pull we didn't have time for. Scope note: this is the whole country's fire signal for the month (wildfires and agricultural burning together), not just the one reported steppe-fire event — Sept 6-8 is the real spike in the actual satellite record. ML cross-check: an Isolation Forest (scikit-learn) run on this same real data independently flags the same Sept 6-8 window as anomalous — run it yourself from ml/anomaly_model.py in the repo.
